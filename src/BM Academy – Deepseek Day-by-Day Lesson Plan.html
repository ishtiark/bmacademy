Day 16 hours

Getting Started & Reasoning

  • 1 hAccount setup, interface tour, chat vs reasoning mode (DeepThink), web search toggle. Privacy rule: never paste personal, financial or client data.
  • 1 hDemo: reading the step-by-step reasoning and asking for explanations, checks and alternative methods.
  • 3 hLab: solve 10 math, logic and business-calculation problems. Verify each answer by hand or in a calculator.
  • 1 hReview, quiz, save best prompts.

Sample prompt

Solve step by step: a shop buys at 800 taka and sells at 1000 taka. Find profit percentage after a 10% discount. Show each step, then double-check the result.

Deliverable

10 solved problems with verification notes

Day 26 hours

Coding Basics with Deepseek

  • 1 hDemo: prompting for code. State language, goal, inputs and outputs. Ask for comments and explanations.
  • 3 hLab: generate a personal web page (HTML, CSS, JS), then ask Deepseek to add a contact form and make it mobile friendly.
  • 1 hLab: paste an error message, ask for the cause and a fix. Repeat with 3 broken code samples.
  • 1 hLab: write a simple Python script for a daily task, such as renaming files or totalling expenses.

Sample prompt

Write a mobile-friendly HTML page for a small bakery with a menu section and a contact form. Use plain HTML, CSS and JavaScript in one file. Add comments.

Deliverable

Working web page + 3 debugging logs

Day 36 hours

Comparison & Workflow Project

  • 1 hDemo: how to test fairly. Same prompt, same task, scored on accuracy, clarity and speed.
  • 3 hLab: run 10 identical tasks on Deepseek, ChatGPT and Gemini. Fill a scoring sheet and note where each tool wins.
  • 2 hMini project: choose the best tool for each of 5 real work tasks and justify the choice in one page.

Sample prompt

Solve the same assigned task with each AI tool. Answer in under 150 words and list any assumptions you made.

Deliverable

Scoring sheet + 1-page tool-selection report

Day 42 hours

Assessment & Showcase

  • 1 hPractical exam: 2 reasoning problems and 1 coding task, solved and verified live.
  • 1 hPresentation of the comparison results, feedback and grading.

Sample prompt

Present the saved prompts and explain how each supports the completed workflow.

Deliverable

Final grade: 50% comparison project, 50% practical exam

Check Deepseek's current privacy policy with students before Day 1 and keep all lab data non-sensitive. Mode names and features change often, so check the interface the day before class.
