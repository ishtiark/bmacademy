Copilot Module

Day-by-day lesson plan for Module 02: Copilot chat plus Copilot in Word, Excel, PowerPoint and Outlook.

20hours
4days
5apps
4deliverables
Day 16 hours

Copilot Chat & Word

  • 1 hAccount setup, Copilot chat interface, web search, uploading files, privacy rules for work documents.
  • 1 hDemo: prompting Copilot in Word. Draft, rewrite, summarize and change tone.
  • 3 hLab: turn rough notes into a formal report, summarize a 10-page document, and create a proposal from an outline.
  • 1 hReview, quiz, save best prompts.

Sample prompt

Draft a one-page proposal for a student-led recycling campaign. Include the objective, timeline, budget table and risks. State any assumptions and use a formal tone.

Deliverable

Formal report + 10-page summary

Day 26 hours

Excel & Outlook

  • 1 hDemo: asking Copilot in Excel for formulas, tables, charts and insights in plain language.
  • 3 hLab: clean a messy sales sheet, add calculated columns, build a pivot summary and two charts. Verify every result by hand.
  • 1 hLab in Outlook: summarize a long email thread, draft replies in 3 tones, schedule follow-ups.
  • 1 hPeer review and practical quiz.

Sample prompt

Add a column that shows profit per product. Highlight rows where profit is below 10%. Then create a bar chart of profit by month.

Deliverable

Analysed Excel workbook + 5 email drafts

Day 36 hours

PowerPoint & Workflow Project

  • 1 hDemo: generating a deck from a Word document, restructuring slides, adding speaker notes.
  • 3 hLab: convert the Day 1 report into a 10-slide deck, fix layout and add notes and images.
  • 2 hMini project: one document, one sheet and one deck for the same business, made end to end with Copilot.

Sample prompt

Create a 10-slide presentation from this document for a manager audience. One key message per slide, with speaker notes.

Deliverable

10-slide deck + end-to-end mini project

Day 42 hours

Assessment & Showcase

  • 1 hPractical exam: 3 timed tasks, one each in Word, Excel and PowerPoint.
  • 1 hPresentation of the mini project, feedback and grading.

Sample prompt

Present the saved prompts and explain how each supports the completed workflow.

Deliverable

Final grade: 50% mini project, 50% practical exam

Before Day 1: Copilot inside Word, Excel, PowerPoint and Outlook needs a Microsoft 365 account with Copilot enabled. If the lab computers do not have it, run those labs in Copilot chat with uploaded files instead. Features change often, so check the interface the day before class.
